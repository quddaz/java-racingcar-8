# java-racingcar-precourse

## ✅ 기능 목록

- [ ] **자동차 이름 입력 기능**
    - [ ] 사용자는 쉼표(,)로 구분된 자동차 이름을 입력할 수 있다.
    - [ ] 자동차 이름은 5자 이하만 가능하다.
    - [ ] 중복된 이름은 허용하지 않는다.
- [ ] **시도 횟수 입력 기능**
- [ ] **자동차 경주 기능**
    - [ ] 각 시도마다 자동차의 위치는 0부터 9까지의 랜덤한 숫자로 결정된다.(camp.nextstep.edu.missionutils에서 제공하는 Randoms)
    - [ ] 랜덤 숫자가 4 이상일 경우 자동차는 한 칸 전진한다.
    - [ ] 각 시도마다 모든 자동차의 현재 위치를 출력한다.
- [ ] **우승자 발표 기능**
    - [ ] 모든 시도가 끝난 후 가장 멀리 간 자동차 이름을 출력한다.
    - [ ] 우승자가 여러 명일 경우 쉼표(,)로 구분하여 출력한다.
- [ ] **예외 처리 옵션**
    - [ ] 자동차 이름이 5자를 초과할 경우 IllegalArgumentException 예외를 발생시킨다.
    - [ ] 중복된 자동차 이름이 입력될 경우 IllegalArgumentException 예외를 발생시킨다.
    - [ ] 시도 횟수가 숫자가 아닐 경우 IllegalArgumentException 예외를 발생시킨다.
    - [ ] 시도 횟수가 0 이하일 경우 IllegalArgumentException 예외를 발생시킨다.
<br>
  
## 🔄 실행 흐름

1.  **프로그램 시작**
2.  **"경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)" 안내 문구 출력**
3.  **사용자가 자동차 이름 입력**
4.  **"시도할 횟수는 몇 회인가요?" 안내 문구 출력**
5.  **사용자가 시도 횟수 입력**
6.  **자동차 경주 시작**
7.  **각 시도마다 자동차의 위치를 랜덤하게 결정**
8.  **각 시도마다 자동차의 현재 위치 출력**
9.  **모든 시도가 끝난 후 우승자 발표**
10. **프로그램 종료**

<br>

## 💻 프로그래밍 요구 사항

- JDK 21 버전에서 실행 가능해야 한다.
- `Application.main()`에서 프로그램을 시작한다.
- `build.gradle` 파일은 변경하지 않는다.
- `camp.nextstep.edu.missionutils` 라이브러리 외 외부 라이브러리를 사용하지 않는다.
- `System.exit()`를 호출하지 않는다.
- 제공된 파일 및 패키지 구조를 변경하지 않는다.
- Google Java Style Guide를 준수하여 코드를 작성한다.

<br>

## ✍️ 커밋 메시지 규칙

- AngularJS Git Commit Message Conventions를 따른다.

- **커밋 메시지 구조**

  ```
  type: subject

  body (optional)

  footer (optional)
  ```

- **Type 종류**

    - `feat`: 새로운 기능 추가
    - `fix`: 버그 수정
    - `docs`: 문서 수정
    - `style`: 코드 포맷팅, 세미콜론 누락 등 (코드 변경이 없는 경우)
    - `refactor`: 코드 리팩토링
    - `test`: 테스트 코드 추가/수정
    - `chore`: 빌드 업무 수정, 패키지 매니저 수정 등

- **예시**

  ```
  feat: 쉼표 구분자로 숫자 덧셈 기능 구현
  ```
